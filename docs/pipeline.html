Design choices that produced those numbers

  • Verifier is deterministic code: invented ids, unretrieved citations and model-written verses cannot pass (adversarial tests).
  • Scope remarks ("not exhaustive", "ask a scholar") are code-owned notes, so the model is never asked for an uncitable sentence.
  • Retry shows the model its rejected answer and a fix recipe; 5 of 38 answers needed it, none needed a third try.
  • Stock phrases (shahada, bismillah) are allowed; a long run or most of a verse is not.
  • Provider-agnostic LLM layer with token counting; a full run is about 300k input and 40k output tokens.
  • Everything beyond the LLM (verify mode, referral, glossary, retrieval) works with no API key.
